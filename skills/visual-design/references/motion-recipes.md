# 八种材质与交互动效

本页定义每种效果的适用对象、实现职责和验收点。先确认组件语义、真实业务状态和当前平台，再选择项目已有的动画能力；新增依赖仍按主流程说明。参数按真实内容、触屏和目标设备校准，不能把同一套弹簧套给所有动作。

## 已确认的采用规则

- **按用途选择，选用后必须按本页实现**。不是所有卡片、按钮、列表都要同时加上这些效果；将采用项与理由记入项目设计约定。
- **按手势类型处理释放**：尺寸调整、侧边栏调整、排序与数据选点继续立即确定结果，不加惯性和回弹；本页的倾斜面板与底部抽屉是明确的弹性复位例外。不能把抽屉的物理参数扩散到普通调整操作。
- **流光轮廓是局部例外**：仅 AI 功能区或重点模块可按需采用动态渐变光晕边框，记录其用途与状态；普通表面仍用微明度分层，不恢复全页普通 1px 边框或无目的毛玻璃。它也不豁免 [Impeccable 反模板检查](design-core.md)。
- [强制界面细节](interface-craft.md) 的字体、数字、焦点、文字出现与复制成功标记规则继续生效；减少动态效果、真实业务状态和资源清理属于每个效果的实现要求。

| 效果 | 主要适用对象 | 关键结果 |
| --- | --- | --- |
| [3D 倾斜光影](#tilt) | 有材质表达需要的独立面板 | 随触点微倾与流光，释放平稳回正 |
| [流体胶囊形变](#morph) | 从操作入口进入加载、状态或面板 | 尺寸、位置与圆角连续，状态与语义准确 |
| [共享元素展开](#shared) | 列表条目进入详情 | 同一对象连续展开，返回能找回原位 |
| [磁吸图表与码表](#chart) | 可按数据点探索的图表 | 指示线、选中点与数字一致联动 |
| [阻尼弹性抽屉](#drawer) | 有多个高度锚点的底部面板 | 边界阻尼，按位移和释放速度选锚点 |
| [动态光晕边框](#glow) | AI 功能区或重点模块 | 轮廓流光与柔和背光共同表达状态 |
| [弹簧交错列表](#stagger) | 新到达的列表或瀑布流项目 | 细微时间差与轻弹上移，不阻碍浏览 |
| [0.96 按压按钮](#press) | 可执行的操作按钮 | 按下压缩与加深，释放轻微超调复位 |

## 1. 3D 倾斜光影面板

**描述词：** 为 card 添加跟随触摸位置的 3D 透视倾斜与模拟镜面反射流光，松手带 spring 阻尼回正。

- 按压后读取触点在面板局部的归一化位置，将横纵位移映射为有上限的小角度俯仰。由外层提供 perspective，内层控制旋转；高光层随局部触点移动，材质与高光共享圆角。
- 高光用渐变或已验证的着色方案模拟，不把跟手亮斑说成真实环境镜面反射。装饰层不截获输入，卡片内的按钮、文本选择和滚动继续可用。
- 镜面高光表达表面受光，与全轮廓旋转光晕不是同一种效果，不能据此给所有面板附加流光边框。
- 释放、取消或失去指针捕获时清理活动状态，以阻尼弹簧回到零倾斜和静止高光；中途再次按下，从当前可见状态接手，不叠加旧复位动画。
- Web 按需要使用 Pointer Events、指针捕获与帧调度，避免每次移动同步反复测量布局；不为跟手效果全局禁用页面滚动。键盘操作不要求模拟触点，提供稳定聚焦态。

**验收：** 四角与中央触点、快速抬手、触屏滚动、取消手势、子按钮点击、窗口缩放和减少动态效果。静态模式保持面板可读、可操作。

## 2. 流体胶囊形变按钮

**描述词：** 实现胶囊按钮向状态或弹窗面板的流体形态变化，尺寸与圆角采用高阻尼曲线无缝过渡。

- 先确定业务终态：加载只需要就地反馈时扩展为状态胶囊；确实需要集中交互才变为面板或对话框，不能为了动效强行弹窗。
- 保持视觉对象连续，记录起止几何，联动尺寸、位置、圆角和表面颜色。使用布局过渡、FLIP 或宿主共享几何能力时，分离容器形变与内容，避免把文字和图标拉伸。
- 高阻尼表现以连续、迅速收敛为目标，圆角与尺寸同步，不反复振荡；这是对流体观感的近似，不代表进行了流体物理求解。
- 加载、成功、失败、取消与返回各有准确终态。业务结果不等动画结束后才更新；防止快速重复触发造成重复提交，动画中断从当前几何继续。
- 成为模态对话框时落实真实对话框语义、初始焦点、背景不可交互、关闭与焦点恢复；视觉上从按钮长出来不能代替这些行为。

**验收：** 加载耗时长短、失败重试、快速重复点击、窄屏、长内容、焦点与关闭。减少动态效果时直接切换到可用终态。

## 3. 共享元素无缝展开

**描述词：** 实现 card 到详情页的共享元素转场，背景与容器连续平滑缩放，返回反向收缩回原位。

- 为原条目与详情的同一对象建立稳定标识，关联几何、背景、圆角与关键图像。容器连续变化，正文采用合适的分层显隐，不把详情文字整体缩放到失真。
- Web 在目标浏览器实测支持时可用 View Transitions 或现有布局动画；原生使用对应共享元素转场。接口存在或默认整页淡入淡出都不足以证明共享元素已正确配对。
- 保持背景色和容器连续，避免白闪、重复影像或突兀推屏。导航、历史、详情数据、滚动位置与焦点语义正常工作，不以一张放大的卡片冒充可操作详情。
- 返回时找到原条目并恢复滚动与焦点；虚拟列表中先恢复正确项目的位置。原条目被删除或过滤后不存在时，使用明确的稳定返回状态，不飞向错误条目或屏幕外的旧坐标。
- 快速返回或再次打开要可中断，清理旧快照与共享标识；不支持转场或减少动态效果时仍能直接导航。

**验收：** 正反向、浏览器返回、深链接、虚拟列表、布局重排、原项目消失、快速中断和目标浏览器；分别记录完整转场与降级。

## 4. 磁吸游标与滚动码表

**描述词：** 折线图横向滑动时吸附最近数据点，指示线与焦点光晕联动，顶部等宽数字用滚动计数器平滑更新。

- 用图表真实坐标变换计算最近有效数据点，按横轴距离吸附，不能把非等距时间序列当作等距数组。指示线、标签、光晕与顶部值来自同一个选中点状态。
- 焦点光晕仅围绕当前探索点缓慢呼吸或短促放大，不遮住折线和相邻点，也不用光晕替代选中状态的其他标记。
- 数字使用 [等宽规则](interface-craft.md) 并预留位数、符号、小数与单位空间。真实选中值立即更新，滚轮只做视觉过渡；中间动画数字不能作为新的真实观测或计算输入。
- 高频移动更新当前目标，不排队补播所有旧数字；停手后准确收敛到所选点。明确缺失值、空图表、多个序列与边界的处理，不凭动效补出不存在的数据。
- 提供键盘或其他离散选点方式，触屏探索与页面滚动协调；辅助技术读取准确值，避免每个动画帧都播报数字。

**验收：** 非等距数据、缺失点、正负与跨位数、快速左右滑动、单位一致、触屏和键盘。减少动态效果时保留磁吸与准确更新，取消呼吸及数字翻滚。

## 5. 阻尼弹性抽屉

**描述词：** 为底部抽屉实现边界橡皮筋阻尼，释放时结合位移与手势速度计算目标高度并吸附。

- 定义合法高度锚点、最大/最小边界和关闭规则，随安全区域、窗口尺寸、软键盘与内容高度重算；不要硬编码永远适用的几档像素值。
- 有效范围内直接跟手，越界后增加非线性阻力，避免整块面板无限漂移。通过近期有效采样估算释放速度，结合当前位置、速度方向和投影位置选择合法锚点，并限制投影极值。
- 选定目标后使用可中断、收敛稳定的阻尼动画；逻辑状态只提交一次，不随弹簧过零反复打开关闭。再次抓住时接管当前实际高度。
- 这是底部抽屉的明确例外；侧边栏宽度调整、列表排序和图表选点仍沿用立即确定结果的规则。
- 协调抽屉拖拽与内部滚动：只在合适手柄或滚动边界交接，不让正文每次滚动都变成收起抽屉；取消、丢失捕获、关闭与卸载释放监听和帧循环。
- 模态抽屉落实焦点、背景、关闭与恢复行为，提供不依赖拖拽的高度切换和关闭入口。动画不能延迟必需内容的访问。

**验收：** 慢拉、快速甩动、边界越拉、反向抓取、内容滚动交接、软键盘、旋转、关闭与减少动态效果。降低动态效果时直接到合法锚点，保留手势功能。

## 6. 动态弥散光晕边框

**描述词：** 为选定重点模块添加缓慢旋转的渐变流光描边，背后附带动态模糊、呼吸式弥散背光。

- 明确它表达的是可用入口、当前活动还是生成中状态；颜色、速度与强度来自项目变量。不得用持续流光伪装真实任务正在运行。
- 仅对选定 AI 功能区或重点模块使用并记录理由，不作为所有卡片的通用装饰；没有用途依据时仍应在反模板检查中移除。
- 将轮廓流光与背光分层：前层沿组件同一圆角轮廓遮罩出细环，后层只模糊光晕源。不能把面板、文字和焦点整体模糊，也不能把普通平面内容都改成玻璃。
- 流光沿轮廓缓慢变化，呼吸幅度克制，不闪烁；不自动套用紫蓝渐变。持续动画在离屏、后台或组件不再活跃时暂停，清理帧循环与观察器。
- 控制滤镜面积和重绘开销，边缘裁剪不截断背光或焦点，光晕不降低文字对比。减少动态效果时改为静止轮廓或微明度强调，仍表达必要状态。

**验收：** 圆角接缝、浅暗背景、模糊范围、文字与焦点、真实业务状态、离屏暂停和目标设备性能。

## 7. 物理弹簧交错列表或瀑布流

**描述词：** 新列表元素用细微交错依次上移入场，每项带微弱物理弹性。

- 仅新到达项目首次入场，采用小位移、弱超调和极小时间差；数据刷新、窗口改变或虚拟列表复用不能反复重播已读项目。
- 使用稳定项目标识，列表与瀑布流的视觉顺序不改变真实 DOM、焦点和阅读顺序；图片等异步内容预留尺寸，避免错把布局跳动当成弹性效果。
- 大批项目限制总体等待，不按索引无限累计延迟。内容到达即可访问，动画不能锁住滚动、点击或键盘；离屏项目不启动无意义编排。
- 与 [文字晕开](interface-craft.md) 协调为同一入场时序，避免外层弹簧与内层逐字延迟叠成多轮等待。

**验收：** 大批量加载、刷新与重排、滚动中追加、虚拟化、图片晚到、焦点顺序。减少动态效果时直接显示稳定布局。

## 8. 弹性微缩反馈按钮

**描述词：** 按钮按下缩放到 0.96 并加深内阴影，释放时轻微超调后回弹至 1。

- 按压态的视觉层精确缩放至 `0.96`，外层布局与命中区域保持稳定；阴影加深表达压入，不只改透明度。放开后短促、轻微超调，再稳定回到 `1`。
- 使用真实按钮语义，将键盘按压、触屏、鼠标和取消状态一起处理；取消或移出后不能卡在 0.96。禁用或业务上不可重复执行的操作遵守实际状态，不能靠弹簧伪装可点。
- 缩放与父级 3D 倾斜使用不同视觉层，避免两个引擎争夺同一 transform。连续点击从当前显示状态接手，不排队播放旧回弹，也不延迟真实动作。
- 这是视觉与深度反馈。真实触觉需要平台和设备支持，不能把 CSS 缩放称为已经震动；未经当前任务授权不额外启用震动或声音。
- 点赞等结果态以实际业务为准；复制成功对勾继续执行 [2500ms 自动恢复](interface-craft.md)，不能因本效果延长驻留。

**验收：** 缩放终值、超调收敛、稳定点击区、键盘、取消、禁用、连续触发与卸载。减少动态效果时用静态深度或立即终态反馈，取消超调。

## 共用交付契约

每个采用的效果记录组件职责、触发与结束状态、参数、打断与取消、布局与焦点、减少动态效果、资源清理及实测范围。优先当前平台已有方案，不因为效果名称擅自新增依赖。静态截图只能证明画面，不能作为跟手、回弹、导航或流畅度的实测。

技术参考：[Pointer Events 与指针捕获](https://www.w3.org/TR/pointerevents3/)、[同文档共享元素转场](https://developer.chrome.com/docs/web-platform/view-transitions/same-document)、[模态对话框交互](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。
