# Agent 能力适配

设计规范和用户约定在不同 Agent 中保持一致，实际执行映射到当前宿主已有、已授权的工具。不要假设安装技能等于安装了浏览器、图像模型、连接器或平台 SDK。

## 开始时确认

读取当前任务提供的文件、工程与工具说明，判断能否读取 / 编辑文件、搜索互联网、观察界面、运行程序和预览产物。只核对影响当前任务的能力，不为小修复执行全套环境探测。

所有本包引用相对当前 SKILL.md 所在目录解析。宿主提供技能根目录时使用该值；没有时根据已加载文件位置定位，不能把工作目录当作技能目录。脚本只在宿主允许且有相应运行时的环境中执行；没有 Python 也能读取全部设计规范。

## 用能力映射工具

| 需要完成的事 | 采用当前可用能力 | 缺少时如何继续 |
| --- | --- | --- |
| 确认用途、方向或新增依赖 | 宿主的交互提问能力或普通对话 | 明确列出问题，等待必要答案；不把超时当作确认 |
| 竞品与官方资料 | 搜索、网页读取、已授权浏览器 | 研究用户提供的资料并说明缺口，不编造线上检索结果 |
| 观察实际界面与流程 | 浏览器、截图、官方演示或产品图 | 对静态截图只判断可见状态，不声称验证完整交互 |
| 界面代码与组件 | 项目文件读写、终端、现有框架 | 可先交设计约定、组件规格或静态稿，说明未运行部分 |
| 位图生成与编辑 | 已授权的图像工具，读取其真实参数 | 保留构图 / 素材方案；未经用户确认不替换计费服务或伪造图片结果 |
| Figma、文档、图表、视频 | 对应已授权连接器、编辑器或本地库 | 按产物需要交付可审阅部分，注明未写入 / 渲染 / 导出的内容 |
| 测试和预览 | 当前宿主支持的构建、浏览器或原生预览 | 提供可复现入口与实际未验证项，不将生成文件当作运行通过 |

图像、浏览器、终端和连接器的具体名称不写死。同一种能力可以由内置工具、MCP 或本地程序提供；额外服务、账号、付费资源和外部写入继续按用户实际授权处理。

## 调用与兼容边界

Codex 的 `$名称`、Claude Code 的 `/名称`、WorkBuddy 的技能选择和自然语言匹配是宿主入口差异，不应修改设计工作流。未支持原生技能发现的 Agent，可以由用户要求读取 SKILL.md，再按需读取它链接的参考；这不等于该产品已实现自动发现。

安装器仅复制本技能，不改模型配置、权限、API Key、浏览器或现有项目指令文件。自动发现取决于宿主版本和配置；图像生成、原生编译和云端文件写入等能力取决于当前环境。不能承诺任意 Agent 都具备全部工具能力。
