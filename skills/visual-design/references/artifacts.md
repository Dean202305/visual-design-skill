# 各类视觉产物的实施

共享需求确认、竞品研究、方向选择、预览和验收；使用各媒介的原生编辑与输出能力。先确认目标格式、尺寸、可编辑要求和当前工具，避免只交一张截图却宣称已完成应用或源文件。

## Figma

明确文件与节点、读取还是编辑、已有组件与变量、协作者要求。先看当前连接器说明及官方 Plugin API，再增量操作；核对字体、Auto Layout、约束、组件实例与变量绑定，返回实际节点或文件位置并查看截图。

设计转代码时先理解组件语义和状态，再映射到项目现有控件。不能只按绝对坐标拼截图。连接器缺失时给出可审阅的设计约定与实现代码，明确未写入 Figma。

## 图片、照片、字体与样机

区分生成位图、编辑原图、矢量资源和确定性排版。保留用户要求不变的主体、文字、比例与透明背景。编辑前查看原图；参考图注明是风格来源、编辑对象还是合成素材。

先制作一个能判断方向的样本，再扩展批次。真实照片处理与生成内容分清；不默认改变人物身份或产品事实。需要字体时检查实际字形、字重、语言覆盖和字体文件使用条件。

使用当前已授权的图像或创作工具，按其真实参数执行；工具失败时说明情况，不擅自更换计费服务。模板、图片和字体的取得来源与使用条件记录到项目。

## 视频与滚动叙事

确认剪辑或生成、时长、画幅、字幕、音频和输出格式。用故事板、关键帧或代表片段确定方向，再制作全片。精确时间戳剪辑使用支持确定性剪切的工具；高光选择不能替代精确剪切。

检查节奏、转场、主体连续性、字幕安全区、编码、首尾接缝与实际播放。滚动叙事要检查 seek、返回、窗口变化、移动端操作、减少动态效果与静态内容。

## 文档、PDF、幻灯片与表格

| 产物 | 实施与验证 |
| --- | --- |
| DOCX / Word | 原生标题、段落、列表、样式、表格、分页和需要的修订 / 评论；实际渲染逐页检查 |
| PDF | 明确页面尺寸、字体、裁切、图像与阅读顺序；需要表单时保留真正可填写字段 |
| PowerPoint / Slides | 保留需要的原生文字、表格、图表与图示；跟随模板主题、母版和版式；逐页预览 |
| XLSX / Sheets | 保留公式、引用、数值精度、重算、数据和图表；验证计算与导出后的显示 |

优先使用已安装并有权使用的对应工具或库。若环境提供依赖定位工具，先读取它的实际返回路径；不要预设某台机器的运行时目录。缺少渲染器时报告未验证部分，不把格式存在当作视觉验收通过。

文档和幻灯片按阅读逻辑排版，不强制套网页卡片。可编辑交付不能被全页栅格图代替。在线文件的权限、共享、评论、发布与消息发送按照用户实际授权处理。

## 图表与网站

图表先确定数据来源、单位、尺度、比较关系与读者，再选择图形。视觉装饰不改变数值含义，验证图例、标签、对比度和非颜色编码。科学图或可分享静态图输出独立文件。

网站沿用现有框架与组件系统。预览先做基本运行检查，确认后检查主要路径、响应式、键盘、状态与资源加载；公开部署按用户授权和实际平台要求执行。
