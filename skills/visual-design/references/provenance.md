# 来源与公开版范围

这是“视觉设计工坊”的公开工作流版本，包含根据需求整理的用途判断、竞品分析、方向确认、组件选择、实现、预览、检查和项目内复用规范。

## 保留的决定

- 按实际用途选择风格，后台重视操作效率，展示型作品可采用更强的视觉与动效。
- 保留平台语义、项目技术栈、原有功能和真实业务状态。
- 新设计先确认用途和限制，给出有差异的方向；明确授权或已有选择继续有效。
- 先预览确认，再完成相关检查与修正；不将截图当作代码、交互或导出已经验证。
- 不预设某种颜色、字体、材质或动效就是更高级；不以重复模板替代设计判断。

## 第三方边界

本仓库没有收录本地私有技能归档、商业插件说明、受限运行时、第三方数据库或付费组件源码。原机器上的整合包可能包含其环境许可范围内的额外工具资源；这些不是公开版的内容。

公开版通过 [产物模块](artifacts.md) 与 [技术入口](resources.md) 保留执行路线。实际处理 Figma、图片、视频、文档、图表或原生工程时，使用所在环境已授权的工具和官方文档，不依赖作者机器的路径。

[六个视觉参考来源](sources.md) 提供用途摘要与官方链接，不代表隶属、赞助或所有资源都能重新分发。具体采用资源要核对作者、许可、版本与使用范围。

本包不包含用户简历、岗位记录、账号配置、密钥、本机路径、迁移状态或恢复备份。安装本公开版不会自动停用、迁移或删除其他技能。
