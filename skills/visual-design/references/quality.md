# 统一质量标准

质量统一，风格按用途变化。先判断使用者要理解什么、完成什么，再组织视觉。界面、图表、图片、文档和幻灯片共享层级与一致性原则，但使用各自的构图和阅读方式。

## 按用途组织

| 用途 | 设计重点 | 常见失配 |
| --- | --- | --- |
| 品牌、官网、发布、作品展示 | 记忆点、作品/产品证据、视觉节奏、明确行动 | 只有特效与口号，产品或作品看不清 |
| 后台、配置、批量操作 | 对象识别、信息密度、选择、筛选、批量反馈 | 把后台做成需要长距离滚动的营销页 |
| 工作台、编辑器、创作工具 | 反复使用的任务、当前对象、工具与产物的关系 | 主要编辑区域被统计卡片与装饰挤占 |
| AI 工作台、长任务 | 队列、当前运行、进度证据、停止、失败/部分成功、产物与成本 | 只用一个无限转圈或聊天气泡代替运行状态 |
| 商业转化、商品、支付流程 | 产品信息、选择、价格和条件、可靠的提交反馈 | 隐藏费用、伪造稀缺、装饰干扰购买信息 |
| 图表与分析呈现 | 比较、趋势、分布或关系的准确表达 | 以装饰性 3D、动画或截断轴改变数据印象 |
| 文档、报告、幻灯片 | 阅读顺序、论证、版式与可读性、编辑要求 | 把每段内容都包装成网页卡片和按钮 |
| 图片、视频、样机 | 主体、媒介、镜头/构图、用途与交付规格 | 裁掉主体或证据，为统一外观损失含义 |

## 可观察的标准

- **层级**：主任务、主标题和关键信息容易辨认；强调数量受内容控制。颜色、大小、间距和位置表达同一层级，不相互冲突。
- **布局**：对齐有依据，重复节奏一致，内容分组来自意义；容器、列数和留白适应真实内容。避免为追求变化而破坏常用导航，也避免所有项目重复同一种页面骨架。
- **排版**：为实际语言和字体设计字阶。中文不机械套用英文超紧字距和行高；检查中英数字混排、标点、长标题和字体回退。先调整表达或布局，再缩小文字。界面文字、表格、投影幻灯片与印刷文档按实际观看条件判断。
- **颜色与材质**：使用有角色的设计变量，覆盖表面、正文、次要内容、边界、强调及语义状态。成功/错误等语义色可以独立于品牌强调色；不要强制整页只能出现一种强调色。材质与背景共同检查可读性。采用 Liquid Glass 时，按 [四层玻璃材质](liquid-glass.md) 分别检查透、折射、高光与阴影；背景模糊按需加入。
- **图像**：真实素材、生成插画、样机和示意图标明各自用途；不把生成画面当作真实事件或产品事实。保留主体、比例和必要证据。素材来源与可用权限按具体资源核对。
- **一致性**：同角色组件使用相同间距、尺寸、字体和行为规则；差异有用途依据。多平台共享概念与品牌变量，具体控件按已确认的平台策略适配。
- **表现力**：允许强视觉与复杂动效；说明它承担的是展示、解释、过渡还是操作反馈。持续运动、粒子、光效和 3D 仍要让阅读与操作成立。

## 改善现有作品

新界面和改版使用 [设计内核](design-core.md)：awesome-design-md 负责蓝图依据，Impeccable 负责识别无依据的模板模式。检查构图、内容、排版和交互是否一起适配，不能把单纯替换强调色当作摆脱模板。

先识别具体问题及影响，再修改对应层。不要把“更高级”“更美观”直接解释为深色、玻璃、渐变、更多留白或更多动画。用户尚未定义方向时展示差异；方向已明确时保持内容、功能与已认可的视觉决定。

视觉评审用实际问题描述：哪里看不清、哪里难比较、哪个操作没有反馈、哪些尺寸破坏排版。风格偏好标为建议，功能缺陷与数据错误标为需要修正；不用未经用户确认的审美禁令冒充通用标准。
