# 用真实画面支持设计判断

用于新方向探索、重设计和视觉评审；局部修复只留受影响区域的证据。借鉴 Huashu Design 的真实初稿、看图打磨与事实检查分工，按本技能已确认流程适配；[固定来源与边界](../resources/design-core/huashu-design/ADAPTATION.md)。

## 方向要能看见差别

- 沿用既有项目、品牌、真实内容和主要任务，先提取可核对的变量和代表组件；不用凭印象重画。
- 对有视觉借鉴的参考，实际打开画面，保留截图或官方示例的具体来源、日期与可见范围。登录页、空白 WebGL 截图、文字摘要不等于看过目标产品。无法截取时记录实际可用的画面与缺口。
- 方向未定时，2–3 个方向使用相同的代表性真实内容，给出可查看的初稿：界面关键屏、文档代表页、图片实际出图、视频方向板与关键帧。不能只列品牌名、色板或用占位矩形冒充初稿。
- 每版说明不同的信息组织、排版层级、材质或素材选择、动效角色，以及与参考的关系。品牌限制下可共享字体和色板，用任务组织与构图产生真实差异；不靠随机挑风格制造差异。
- 已选定方向的迭代、机械修改和明确授权沿用既有决定，不新增固定的六候选门槛。

## 看原尺寸，再改实际问题

方向初稿先完成基本运行检查，打开原尺寸代表画面，修正最影响选择的缺陷，再供用户选择。完整预览按既定顺序交给用户确认，之后再做全面检查。

长页面逐视口查看，文档/幻灯片逐代表页或逐页查看；在目标尺寸检查首屏含义、主次层级、真实内容、对齐/间距、断行/溢出、素材与方向一致性。手机和桌面分别看，不把一张缩得很小的长截图当成检查完毕。

每轮只处理最有影响的问题，必要时保留修改前后同尺寸、同状态的截图。新问题或受影响路径才继续复查；没有实际问题就停止。如果同一问题经过两次修正仍无改善，先诊断内容/结构/工具，给出具体改法或环境缺口，不无限磨样式。用户需要决定的新方向仍等选择。

复用项目已有记录，必要时用 [证据模板](../assets/templates/design-evidence.md)：来源 → 方向 → 用户原话/选择 → 修改 → 复查。记录留在当前项目；没有授权不写全局偏好档案。用户在一个项目的选择不是所有项目的新禁令。

## 作品事实检查：浏览器采集 + 标准库分析

`scripts/validate.py` 检查技能包，不检查作品。新增的 `scripts/design_audit.py` 只检查它实际采集到的浏览器事实，不等同 Impeccable 原版检测器，也不判断好看或宣布合规。

1. 用当前宿主已有、已授权的浏览器打开待检查界面，等待本次资源和字体稳定。只对本任务页面执行，不额外安装运行时或调用外部服务。
2. 从技能根目录运行下方命令取得函数源码；通过当前浏览器的受支持 JavaScript 求值工具执行该函数，将返回对象原样保存到项目证据目录的 JSON。函数只读 DOM 和计算样式，不点击、不修改页面，不读取表单值。它仍会包含短正文片段，按项目隐私范围保存，不能自动公开。
3. 同时保存当前视口截图、页面状态与采集时间。其他尺寸、主题或关键状态分别采集。控制台/网络错误需要浏览器工具单独观察并记录，此采集器无法回溯。
4. 对保存的数据执行检查：

```bash
python3 scripts/design_audit.py collector
python3 scripts/design_audit.py check "/项目证据目录/snapshot.json"
# 项目确实有字号阈值时才指定，单位 CSS px；不是通用合规阈值
python3 scripts/design_audit.py check "/项目证据目录/snapshot.json" --min-text 14
```

| 输出 | 含义与处理 |
| --- | --- |
| `failures` / 退出码 1 | 当前布局中未隐藏的图片已加载完成但解码宽度为 0，需检查资源及截图。修正后重新采集。 |
| `review` | 横向溢出、加载中资源/字体、项目字号提示、未支持内容等。结合画面判断；允许的横向滚动不能自动判错。 |
| `unverified` | 美感、对比度、实际字体字形、交互、动态效果、控制台、未访问内容等均需另外验证。无失败时状态仍为 `needs_review`，不是 `pass`。 |
| 退出码 2 | 输入缺失、格式错误或证据不完整。不能记为“检查通过”。 |

采集只支持普通 DOM 正文和 `<img>` 的布局可见性，不证明元素无遮挡或在当前视口内；不覆盖 iframe、Shadow DOM 内部、伪元素、SVG/canvas、背景图、完整可访问性树或所有交互状态。字号为计算样式值，不是实际字形像素或可读性结论。明确这些缺口，避免用简易色彩算法错误判定玻璃、渐变和图片上的文字对比度。

没有 DOM 求值能力时，使用已有截图/原生检查能力并标明未运行此工具；不伪造 JSON。不把 Web 采集器用于原生控件或替代原生构建、文件渲染及导出检查。
